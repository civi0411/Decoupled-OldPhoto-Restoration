# Synthetic Crack3D Pairs

This directory represents generated synthetic crack image pairs, masks, and related metadata used for synthetic pretraining.

Full synthetic datasets are external and intentionally excluded from Git. The repository stores manifests, split metadata, and small examples only.

Use `data/manifests/synthetic_crack3d_manifest.csv` and `artifacts/manifests/reproduction_runs_manifest.csv` to follow dataset-to-run lineage.
